## Описание🪪
**Приложение для анализа транзакций, которые находятся в Excel-файле. Приложение будет генерировать JSON-данные для 
веб-страниц, формировать Excel-отчеты, а также предоставлять другие сервисы.**

## Описание функционала:🪄
* Модуль **views.py** содержит функцию *main_page* и вспомогательные функции для генерации JSON-данных для веб-страницы
"Главная". Медленная работа модуля связана с необходимостью выдержки временного интервала между запросами на сервер со
стоимостью акций (не более 1 запроса в секунду, ограничение 25 запросов в сутки) из-за использования бесплатной версии 
API. Изменяя настройки в файле json-settings можно выводить информацию об интересующих курсах валют и акций. Изменяя 
дату в функции *main_page* мы получаем данные по операциям с 1-го числа указанного месяца по текущую дату.
* Модуль  **utils.py** содержит настройки всех логгеров. 
* Модуль **services.py** содержит функции для поиска категорий выгодного кэшбэка (*get_best_cashback*) за указанный месяц
года, функцию поиска переводов физическим лицам (*find_remittance_to_people*), функцию подсчета суммы, отложенной в 
инвесткопилку за счет округления всех трат (*investment_bank*), а также вспомогательные функции.  
* Модуль **reports.py** содержит функцию составляющую отчет по тратам в указанной категории и за последние 3 месяца от 
указанной даты или от текущей даты, если дата не указана. Функция декоратор сохраняет данные в файл Excel.

## Запуск🚀
- Запускаем команду в терминале `python src/views.py`, при этом выдаются данные JSON для веб-страницы "Главная".  
- Запускаем команду в терминале `python src/services.py` при этом запускаются сервисы расчета инвесткопилки, поиска 
переводов людям и категорий выгодного кэшбэка (данные в формате JSON).  
- Запускаем команду в терминале `python src/services.py` при этом формируется отчет о тратах в заданной категории за 3
месяца до указанной даты (или текущей даты).
